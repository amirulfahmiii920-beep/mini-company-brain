## 3. Tools

- Slack for chat. Main channels: #rakanpay-v2, #engineering, #general.
- GitHub for code and pull requests.
- Linear for tasks. The v2 board is called "RakanPay v2".
- Figma for designs.
- Stripe test dashboard for payment testing (ask Danial for access).

## 4. How the team works

- Stand-up every Monday at 10:00, plus a short daily check-in on Slack.
- Every change goes through a pull request with at least one reviewer.
- Jason runs regression tests before every release.
- The team's shared office day is Wednesday.
- **Remote work:** you can work from home up to 3 days a week. Just let the team know in
  #rakanpay-v2 which days you are remote.
- Core hours are 10:00 to 16:00.

## 5. Where the project is now

We are aiming to launch RakanPay v2 on 15 December 2026. The mobile app is the biggest
piece of work left, which is why we are so glad you are here.
